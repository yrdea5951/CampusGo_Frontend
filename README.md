# CampusGo Front-End Demo

واجهة عربية RTL متجاوبة لفكرة منصة خدمات جامعية.

## التشغيل
1. فك ضغط الملف.
2. افتح المجلد في VS Code.
3. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.
4. جرّب اختيار خدمة، تعبئة نموذج الحجز، واختيار الموعد والدفع.

## الملفات
- `index.html`: هيكل الصفحة والنموذج.
- `style.css`: التصميم والتجاوب مع الموبايل.
- `script.js`: اختيار الخدمة والميعاد والتحقق من النموذج وعرض ملخص تجريبي.

## تنبيه مهم
هذه نسخة Front-End تجريبية فقط. الطلبات تحفظ محليًا في LocalStorage على نفس المتصفح، ولا تُرسل إلى سيرفر أو مكتب طباعة. لا يوجد دفع حقيقي. قبل الإطلاق تحتاج Backend بـ Laravel، قاعدة بيانات، رفع ملفات آمن، لوحة للمكاتب، إدارة المواعيد، وتكامل دفع رسمي.
